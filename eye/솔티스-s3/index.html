하루 종일 사용해도 눈피로는 덜 하나요

처음에는 기존에 쓰던 렌즈가 눈에 잘 맞았기 때문에 굳이 바꿀 필요 있나 싶었어요. 그런데 요즘 들어 눈물이 자주 나고 시력보호에도 신경 쓰이기 시작했거든요. 특히 회사에서 하루 종일 컴퓨터 앞에 앉아 있다 보니까 오후만 되면 눈이 뻑뻑하고 시야가 흐릿해지는 느낌이 들어요. 예전에는 잘 몰랐는데 요즘은 퇴근할 때쯤 되면 눈이 너무 피곤해서 렌즈를 빼는 순간이 제일 개운하다는 느낌까지 들 정도예요. 회의 들어갈 때 모니터랑 화면 번갈아 보다 보면 눈이 순간적으로 안 맞는 느낌이 들 때도 있어서, 이게 나이 때문인지 렌즈 때문인지 헷갈릴 때도 많아요. 주말에 렌즈 안 끼고 안경만 쓰고 하루 보내면 그나마 눈이 좀 쉬는 것 같아서, 평일에도 이렇게 계속 무리를 줘도 되나 싶은 걱정이 들더라고요. 월요일 아침에 다시 렌즈 낄 생각하면 벌써부터 눈이 뻑뻑해지는 것 같은 기분이 들 정도라니까요.

특히 하루 종일 컴퓨터 작업을 하다 보니 눈피로가 너무 심해져서 뭔가 대책이 필요할 것 같아요. 솔티스 s3 렌즈가 괜찮다는 얘기를 들었는데 진짜일까요? 그래서 지난주부터 본격적으로 정보를 알아보기 시작했는데, 생각보다 실제 사용자 후기를 찾기가 어렵더라고요. 커뮤니티 여기저기 검색도 해보고 블로그도 몇 개 들어가봤는데 다들 광고 글 같아서 믿음이 잘 안 가고, 진짜 착용해본 사람 얘기가 궁금해서 이렇게 글을 남기게 됐어요. 안구건조 증상이 있는 분들은 어떤지도 궁금해요. 저는 특히 사무실 에어컨 바람을 오래 쐬면 눈이 더 건조해지는 느낌이라 이런 부분도 사람마다 다를 것 같아서 여쭤보고 싶어요. 여름이라 그런지 에어컨 바람 세기가 유독 세게 느껴지는 자리라서 그런지 오후만 되면 눈이 따갑고 시린 느낌까지 들 때가 있어요. 퇴근 후에 운전할 때 맞은편 차 불빛이 유난히 번져 보이는 것도 요즘 신경 쓰이는 부분이라, 렌즈를 바꾸면 이런 것도 좀 나아질지 궁금하더라고요.

렌즈 가격과 성능 비율은 좋나요
